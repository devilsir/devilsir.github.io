# ATRAÇÃO FINAL

Projeto enxuto para GitHub Pages.

## Publicar

1. Envie todos os arquivos desta pasta para a branch `main` do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment → Source**, escolha **GitHub Actions**.
4. Aguarde o workflow **Publicar no GitHub Pages** terminar.

## Rodar localmente

```bash
npm install
npm run dev
```

## Controles principais

- WASD: movimento
- Mouse: câmera
- E: interagir
- Tab: inventário
- H: guia luminoso
- F: tocha
- Clique esquerdo/direito: ataques
- Esc: fechar interface ou pausar
